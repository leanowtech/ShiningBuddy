# Shining Buddy v0.9.9-rc.8

## Bug fixes

- 修复长任务将越界清理、文件版本冲突和授权变化误报为工具连接故障的问题。被拒绝的调用返回具体原因，其他步骤可以继续。
- 控制响应丢失时按原调用查询回执。已确认完成的操作保留结果，效果仍不确定的操作保留待核对，避免重复执行或投递。

## UX improvements

- 只读状态暂时无法查询时显示未知。需要重新读取文件或核对权限时，工具给出对应提示。

## Breaking changes

- 无。沿用现有实例目录和启停脚本，升级流程见 [保留数据升级](../docs/upgrade.md)。

macOS ARM64 实机升级、Linux 和 Windows 交叉构建分别验证。
