# Shining Buddy v0.9.9-rc.5

## New features

- 微信里可以查询之前的附件投递状态，并补发经核验的原件。补发无需重跑任务。

## Bug fixes

- 修复项目附件生成后未保存、导致通知只有文字的情况。
- 修复前台命令转后台后卡住同一任务的问题。助理可以查看原作业并继续处理。
- 修复模型凭据在排队中到期时的请求失败，允许在原时限内重新准备凭据。
- 修复无效的浏览器预览地址引发的错误，保留任务已有进度。

## UX improvements

- 微信的长等待提醒会区分等待模型、等待工具和正在执行工具步骤。
- 报告预览提示会引导助理用当前文件快照预览和打印，减少无谓等待。

## Breaking changes

- 无。沿用现有实例格式和 kvault 0.5.0-rc.2。
