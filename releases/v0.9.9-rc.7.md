# Shining Buddy v0.9.9-rc.7

## New features

- macOS 和 Linux CLI 发行附带 `start.sh`、`stop.sh`。脚本随安装目录移动，也可通过参数指定已有实例与 CLI。

## UX improvements

- 启动确认实际运行的版本和构建，再显示解锁或工作台入口。停服区分已停止和仍在等待，并支持接管已有 macOS 保活任务。
- 移动端工作台沿用自己的导航，移除重复预留的顶部空白。

## Bug fixes

- 内置 DeepSeek Harness 升级到 `0.2.2-rc.5`。修复切换模型时可能过早触发历史压缩的问题，验证旧会话续跑、文件审批和 Shell 占用回收。

## Breaking changes

- 创作模式随上游用 `dsh-doc` 替换旧的内置 Harness 开发 Skill 入口。实例内管理的 Skill 及其已保存版本可继续使用。

启停脚本需要 Python 3，Windows 继续使用启动器或 CLI。保留原实例目录，升级步骤见 [保留数据升级](../docs/upgrade.md)。Linux 和 Windows 构件为交叉构建，目标机器实机验收单独记录。
