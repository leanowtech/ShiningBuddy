# Shining Buddy v0.9.8-rc.8

## New features

- 主助理可以按需调用已配置模型、工具和技能，组建临时 Buddy。文本主模型遇到图片时，可请视觉模型读图，再统一回答，无需切换整个对话的模型。
- 支持长期 Agent：配置职责、模型、工具、技能和预算；在 Agent 库、项目或当前对话中创建、编辑、试用和绑定。
- 项目默认助理可由对话单独覆盖，也可恢复继承；临时协助可保存为长期 Agent。
- 提供无工具的轻量模型协助与完整 Worker 两种执行方式，支持材料引用、多轮追问和结果回读。

## Bug fixes

- 修复旧脚本凭据导入及历史待核对清理在新版 kvault 下受阻的问题；核对清理不读取秘密、不重复删除。

- 五个平台的 kvault 统一升级到 **0.5.0-rc.2**，采用定向凭据读取和同一签发请求的断链恢复；保留原读取时限，已执行工具不会因凭据重试而重跑。
- 补齐升级后解锁、启动票据与旧 Vault 升级的凭据身份登记，登记前保存一致性备份，已有身份不会被普通读取改绑。

- 文本主模型读取历史图片或工具图片时，保留原图和可验证引用，避免因输入类型不兼容中断。
- 修复 MCP 图片在日志脱敏后失去原始内容的问题；图片按当前范围和版本读取。
- 创建 Agent、加入项目或对话发生冲突、响应丢失或进程中断时，可以核对原请求并继续，避免重复创建。
- 会话私有 Agent 的定义、笔记、运行、成员和材料保持会话隔离；编辑共享模板来源时不会改写其他 Agent。
- 成员完成后的结果交接与用量分别持久化；重启后核对已有结果，不重跑已完成的模型请求。
- 修复模型能力配置保存时的字段冲突；普通项目和对话编辑保留已有助理绑定。
- 协作或材料引用版本不匹配时返回已授权范围内的当前事实与未执行状态，帮助模型核对后恢复；能力候选采用较短的版本标识，减少转录长版本串造成的重复失败。
- 修复版本维护页自动刷新后吞掉操作失败提示的问题；失败后需重新读取任务，旧请求不会恢复过期按钮。
- 长期 Agent 配置工具使用明确的模型字段，修复格式错误反复报“模型未配置”的恢复缺口。

- 凭据目录刷新保留已展开的用途与操作；用途变更、迟到响应、读取失败或确认框失效时，核对当前事实并停用过期操作。

- 执行历史的项目筛选增加索引，减少概览查询的重复读取与 JSON 筛选；保留原历史归属和排序。

## UX improvements

- 对话显示当前助理及配置来源；项目和对话均提供“助理与协作”入口。
- 协助过程显示实际阶段、等待原因和结果；长期配置状态与正在执行状态分开。
- 保存冲突保留草稿，支持读取差异、核对保存结果与继续原加入步骤。
- 模型能力声明与近期调用观察分开展示，不把连接成功写成图片理解质量已验证。
- 能力不足或协作被关闭时，说明本轮实际可用范围，避免反复读取图片引用仍无法完成。
- 手机设置页保留折叠的高级管理入口，可返回跨会话任务、远程连接和执行诊断。

## Breaking changes

- 使用新 Agent 或媒体历史后，请保留当前或更新的程序。兼容回退会拒绝将这些记录交给不支持的旧版本；如需回退，应恢复独立的完整升级前实例。
- 上层关闭协作、禁止临时组建或排除某个模型时，较小范围不能重新开启。
- 这是预发布版本。升级不会自动创建永久 Agent，也不会修改已有定时任务的明确执行目标。
