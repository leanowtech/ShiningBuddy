# Shining Buddy v0.9.9-rc.6

## New features

- 微信网页登录审批同时显示请求 IP 和浏览器 UA。通过反向代理访问时，IP 可能是代理地址。

## Bug fixes

- 工具接口响应暂时丢失时，按原调用核对和恢复，减少授权或额度等待超时导致的任务中断。
- 已收到完整凭据授权时立即开始读取，避免等待管道关闭卡住模型或工具。
- 缩小旧任务占用的影响范围。无关任务可以继续，仍有冲突的操作按原执行证据核对。
- 将可选清理与任务成果和通知结算分开。清理失败时保留已完成的报告和附件。

## UX improvements

- 工作台轮询只计算待处理审批的授权范围，减少大量历史审批对工具授权和界面响应的影响。
- 修复加载更早消息时的滚动定位，以及迟到的刷新覆盖正在编辑的技能设置。

## Breaking changes

- 无。沿用现有实例格式和 kvault 0.5.0-rc.2。
