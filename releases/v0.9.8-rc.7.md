# Shining Buddy v0.9.8-rc.7

## New features

- 新增工具占用查询与证据复核能力；助理可定位原调用，由 Host 自动解除已证明未执行或已完成的残留占用。

- 受限巡检可检查等待凭据、审批和输入的运行，并记录哪些需要本人处理。

## UX improvements

- 工具运行诊断增加“按执行证据自动核对”，显示仍在执行或缺失证据的具体原因。
- 本机与 SSH 工具结果标明执行来源、项目目录及观察时间，减少跨主机误诊。

- 巡检提醒由 Host 的真实回执决定，模型漏写或误写标记不再导致漏提醒或多余提醒。
- 已解决的等待不再继续计入当前人工处理数量；报告区分恢复运行成功与通知被平台接受。

## Bug fixes

- 修复启动阶段切换时管理连接短暂不可达、实例概览误报未核验，以及 CLI 只检查旧 ready 快照的问题。
- 修复原生工具前置失败后残留未知占用、导致后续 Bash 一直受阻的问题；恢复不会重跑原操作。
- 显式临时文件清理只准备指定目标，并限制扫描节点、字节和耗时，避免小范围清理被无关目录拖慢。

- 自动恢复在原任务暂停、删除或变更后停止提交或启动；保留本人手动续接能力。
- 自动续接沿用原运行有效时限，不因实例默认时限调大而越过原上限；历史时限无法核实时转人工。
- 保留批量提交回滚、跨库原身份复用和未知效果保护。

## Breaking changes

- `maintenance_finish` 的自动动作必须提供当前观察到的 `expectedJobVersion`。旧调用缺少字段时明确拒绝，不猜测版本。
- 旧自动恢复记录缺少任务约束快照时不会自动启动，需要本人核对。升级不会自动修改任务或开启恢复授权。
