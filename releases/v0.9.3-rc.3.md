# Shining Buddy v0.9.3-rc.3

此版本为预发布候选，准备 macOS ARM64 GUI 与 CLI。

## 本次改动

- 普通发行包移除核心开发源码、测试工程、第一方类型声明与 source maps；保留运行 JavaScript、凭据 SDK、框架文档和第三方许可证。
- 压缩归档解包后独立检查，原生启动自检也核验实际运行目录。
- 核心代码开发需要显式提供匹配源码；日常记忆、Skill、任务、指令与权限配置继续可用。
- 增加 GitHub 草稿发行流程，白名单上传后下载回验，公开文档与核心源码使用独立历史。

## 升级与已知边界

停止原服务，备份程序、实例与外部项目，再替换程序并选择原数据目录。无需清空实例、重新绑定微信或重建 vault，实例格式不推进。

以附件中的实际平台与验证状态为准。macOS GUI 为 ad-hoc 签名，未完成 Apple 公证。未列出的 Linux、Windows 包不在本次 macOS 构建范围内。

上一候选默认 Chrome 的实包导航检查在长文就绪阶段超时，软件渲染功能回归通过。该性能验收项尚未完成，不能将本候选描述为全平台正式验收版本。

Node 和 WebUI 运行需要 JavaScript 与脚本；去除开发源码不代表不可逆向。
