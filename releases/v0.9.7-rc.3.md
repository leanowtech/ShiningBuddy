# Shining Buddy v0.9.7-rc.3

本版修复凭据已经解锁、助理可以正常响应后，任务列表仍持续显示「等待解锁凭据」的问题。

## 凭据恢复与任务状态

- 有明确未执行记录的任务在解锁后自动恢复排队。
- 执行中因凭据锁定而中断、结果仍需核对的任务，解锁后显示「待核对执行结果」，保留已有成果，不自动重跑。
- 旧版等待记录缺少未执行证明时，转为待核对；无需继续重复解锁。
- 定时任务、专家协作及会话请求同步修正，任务概览、运行列表与详情自动刷新恢复后的状态。
- 旧等待状态不再阻挡同一定时任务的下一次正常触发。微信换绑期间仍保留执行准入限制，同时更新已经恢复的凭据状态。
- 恢复定时任务时，运行记录和计划发生记录一并提交；写入失败会回滚。已取消的任务保持取消状态。

## 升级

保留原 data-dir，正常停止服务、替换程序并重新启动；需要时在 WebUI 解锁凭据。新服务会自动整理旧的凭据等待状态，无需手动修改数据库或清空历史。

仅替换 CLI 不会更新已经运行的服务。请用 `service status` 核对运行版本为 `0.9.7-rc.3`。标记「待核对执行结果」的记录表示执行可能已经产生操作，应先查看已有进度和成果，再决定是否继续。

本版沿用现有实例格式，不新增配置来源。五个平台继续内嵌 **kvault 0.5.0-rc.1**，并包含 rc.1 的浏览器目录修复和 rc.2 的微信多任务输入状态提醒。

## 构件与验证范围

提供 macOS arm64 GUI/CLI、Linux arm64/x64 CLI，以及 Windows arm64/x64 GUI/CLI。macOS 使用 ad-hoc 签名，未做 Apple 公证；Linux/Windows 为交叉构建，不代表目标机器实机升级验收。

恢复流程覆盖未开始任务、执行结果未知、旧记录、换绑准入、原子回滚和下一次定时执行，并使用真实浏览器核对自动刷新、任务详情与结果保留。验证使用隔离合成数据，不读取留存实例或真实凭据。

这是预发布版本。仅接收正式版的实例不会被强制切换到 RC；可在「设置 → 界面与系统 → 版本维护」选择接收预览版，或手动安装。
