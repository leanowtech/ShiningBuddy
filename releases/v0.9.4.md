# Shining Buddy v0.9.4

本版本集中改善旧实例升级、存储迁移和启动恢复，并重新提供 macOS、Linux、Windows 安装包。日常运行继续使用一个 `data-dir`，实例配置保存在其中的 `config.toml`。

- 修复微信连接浮层关闭后重新打开时旧请求阻塞资料读取的问题；连接状态轮询随浮层关闭而取消。

## 启动与升级

- 启动先建立受限管理入口。整理数据时可查看进度、诊断原因，并在安全检查点停止；管理入口可达与业务可执行分别核验。
- 迁移、凭据解锁或升级放行尚未完成时，定时任务、协作与消息投递保持暂停，不把 `ready: true` 当作业务已经恢复。
- 短暂 SQLite 锁竞争采用有界等待，避免一次快照读取立即失败而导致启动受阻。
- 升级收尾失败保留诊断和业务暂停状态，便于继续处理，不再忽略错误后宣称完成。

## 迁移与恢复可靠性

- 恢复前先核验整份备份的文件清单、摘要与 SQLite 完整性；后面的备份损坏时，不会先改动前面的数据库。
- 恢复开始前持久记录恢复屏障。进程中断后继续原恢复，未完成时不开放混合状态的业务数据。
- 迁移进度绑定稳定对象 ID、实际输入、文件身份和配置版本；新增控制库先补备份，已有输入被修改、替换或删除时停止陈旧计划。
- 上下文迁移使用实例租约与机器、进程启动身份。可证明的孤儿锁可恢复，活动或身份未知的拥有者不会因超时而被强行接管。
- 已接收新写入的实例拒绝自动恢复旧备份；冻结批准、结果未知的执行和待通知记录不会被消费或重放。

## 配置与路径

- `inspect`、预览和路径编码保持只读。可自动确认的根声明在有备份和配置版本校验的提交边界处理。
- 保留已有项目、外部根与实例根引用的身份，避免重新猜测归属；继续兼容退休 JSON 中的历史目录别名，正常读取以统一配置为准。
- 凭据保护模式保存于实例内 `config.toml`，旧启动器偏好在导入时归档，不增加长期覆盖来源。
- 损坏或过大的历史记录保留原文并给出对应范围的诊断；不会为了启动而全文替换历史路径或删除原文件。

## 安装包与依赖

| 系统 | 附件 | 验证边界 |
| --- | --- | --- |
| macOS Apple Silicon | GUI ZIP、单文件 CLI | 本机构建与实包启动、升级、停止检查 |
| Linux ARM64 / x86_64 | 单文件 CLI | 交叉构建；目标平台实机运行待部署后核验 |
| Windows ARM64 / x64 | GUI ZIP、单文件 CLI EXE | 交叉构建预览；Windows 实机运行待核验 |

内嵌 Node.js `24.18.0`。kvault 按现有平台依赖分别打包：macOS 为 `0.5.0-rc.1`，Linux 为 `0.4.1`，Windows 为 `0.3.0`。本次没有替换这些已锁定的上游版本。Linux 凭据服务要求内核 `5.3` 或更新版本。

macOS 使用 ad-hoc 签名，未完成 Apple 公证；Windows 构件未签名。macOS GUI 的完整人工操作流程、真实模型响应、微信手机送达和手机浏览器不包含在工程验收中。平台 manifest 分别记录实际验证状态，交叉构建不会被标为目标系统运行通过。

## 升级与回退

1. 等待当前任务结束，正常停止旧服务；仅关闭 GUI 不会停止后台服务。
2. 备份原程序、实例数据目录与外部项目目录。运行期 socket 不作为普通归档文件。
3. 完整替换 GUI 应用或 CLI 程序，继续选择原 `data-dir`；核对系统自启动登记的程序路径。
4. 打开工作台，等待维护完成，并按提示使用原主密码解锁。再核对项目、会话、定时任务和凭据。
5. 核对状态中的运行版本与业务准入。未知执行先查记录，不直接重跑。

配置格式仍为 `3`、身份格式仍为 `2`、PathRef 表示仍为 `1`；维护协议与最小存储写入器能力提升到 `3`。新维护协议启用后，旧 CLI 会在写入前拒绝访问。不要通过删除 journal、锁、任务库或 vault 来尝试降级；回退数据需使用匹配的升级前备份，已有新写入时不会自动覆盖。

缺少证据的旧数字 checkpoint 不会被清空后猜测续作。遇到维护受阻时保留原数据、回执和备份，按页面诊断继续处理。

## 构建与验证

本版以冻结的私有源码提交与源码 SHA-256 标识构建，公开 Release tag 指向独立的发行文档提交。安装包、GUI 内嵌 CLI、kvault 目标架构与摘要分别核验；附件上传后下载回验。

启动恢复检查覆盖实际进程终止、恢复屏障、目录增量、锁竞争、配置并发变更、旧写入器拒绝与原数据保留。实包升级覆盖未版本化实例、现代实例和失败续作，并检查实例根及嵌套项目资产。最终源码与平台构件身份以 `release-manifest.json` 为准。

公开仓库仅用于安装包、说明和手册，不接收核心源码 Git 历史。普通安装包不附带核心开发源码或第一方 source maps；运行 JavaScript、凭据 SDK 和第三方许可仍随程序分发。

升级步骤见附带的 `UPGRADE-GUIDE.md`。下载单个文件时将 SHA-256 与 `SHA256SUMS` 同名条目比较；下载全部清单文件后，可在 macOS 执行 `shasum -a 256 -c SHA256SUMS`，Linux 执行 `sha256sum -c SHA256SUMS`。
