# Shining Buddy v0.9.7-rc.1

本版修复定时任务将正常的私有浏览器目录误判为配置变更，导致 `browser_restart_required`、网页读取降级或失效的问题。

## 浏览器修复

- 定时任务继续使用独立的浏览器资料目录和每次运行的输出目录，配置变更校验改为对照原始实例配置，避免把运行目录差异误判为配置变化。
- 未修改配置时，同一定时任务连续运行均可正常使用浏览器和 `web_fetch`；前台会话、专家协作与定时任务分别按各自的连接使用浏览器。
- 实际更改实例浏览器路径后，仍拒绝使用旧连接。未确认结果的浏览器写操作不会因本次修复而自动重放。
- 新增从真实 TaskHost 调度入口、统一 TOML 配置到 Chrome 网页读取的回归测试，同时覆盖真实配置变更的反例。

## 升级

这是预发布修复版本。保留原 data-dir，正常停止服务、替换程序并重新启动；不要清空项目、任务、浏览器资料或 Vault。仅替换 CLI 不会更新已运行的服务，请用 `service status` 核对运行版本为 `0.9.7-rc.1`。

五个平台内嵌 kvault 均保留 **0.5.0-rc.1**。延续 v0.9.6 的零模型官方版本检查、签名清单和确认后更新；本版不增加实例格式迁移，也不增加新的配置来源。

自动检测是否提示本版取决于实例的版本通道设置。仅接收正式版的实例不会被强制切换到 RC；可在「设置 → 界面与系统 → 版本维护」选择接收预览版，或手动安装。

## 平台与验证边界

提供 macOS arm64 GUI/CLI、Linux arm64/x64 CLI，以及 Windows arm64/x64 GUI/CLI。macOS 使用 ad-hoc 签名，未做 Apple 公证；Linux/Windows 为交叉构建，不能视为目标机器实机升级验收。

发行验收覆盖实际定时任务与 Chrome、网页读取、未知结果保护、类型检查、实例自包含与修复、启动恢复、真实 dsh 和安装包。测试使用隔离实例与合成资料，不读取留存生产实例；真实用户机器、模型语义和微信手机送达不由这些夹具代替。
