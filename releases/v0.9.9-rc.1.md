# Shining Buddy v0.9.9-rc.1

## New features

- 支持直接交付 Markdown 新稿，无需先写入项目或经 Shell 生成文件。

## Bug fixes

- 本机凭据访问超时时，若模型请求尚未提交且原期限仍允许，尝试重新获取一次凭据。已执行的工具和已提交的模型请求不会重放。
- macOS 和 Linux 有序停止后台 Bash 时，确认受管进程已退出后释放工具占用。旧命令的业务结果仍可核对，后续任务可以继续。

## UX improvements

- Host 自动检查与当前操作冲突的旧占用。本机旧 Shell 缺少退出证据时，仍可读取、搜索和交付已有成果。

- 诊断区分凭据授权、读取和本机结果回传，明确显示模型请求是否已经提交。
- 工具运行诊断说明缺少哪类退出证据，以及哪些占用已解除。

## Breaking changes

- 无。沿用既有配置、任务和 kvault 0.5.0-rc.2。
