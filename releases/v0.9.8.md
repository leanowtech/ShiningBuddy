# Shining Buddy v0.9.8

本正式版汇总 0.9.8 系列预览版的能力协作、失败恢复、微信通知和稳定性改进。

## New features

- 按需组建临时 Buddy，调用已配置的模型、工具和技能。文本主模型可以请视觉模型读图，再统一回答，无需切换整个对话模型；支持轻量模型协助和完整 Worker。
- 支持长期 Agent：配置职责、模型、工具、技能和预算，在 Agent 库、项目或对话中创建、编辑、试用和绑定。对话可覆盖项目默认配置，也可恢复继承；临时协助可保存为长期 Agent。
- 新增受限巡检与失败恢复能力。本人授权检查范围、动作和预算后，可续接未完成的运行，或恢复已证明未发送的原有结果；提供 CLI 授权和巡检报告。
- 新增工具占用诊断与按证据恢复。可自动解除已证明未执行、已完成或跨系统重启的本机残留占用；未知业务结果保留，不重跑原命令。
- 支持任务独立运行时限、最长 24 小时预算，以及按当前版本延长在途执行；可从原检查点续接，保留项目、模型和权限。
- 本机 `web open` 可获取短时、单次管理链接，微信投递故障或冷却时也能进入工作台；Vault 锁定时仍需解锁。
- 微信通知在本地发送保护预算不足时暂存，回复指定续接码后继续发送；也可预演、补发选中的已有通知内容，无需重新生成成果。

## Bug fixes

- 修复后台命令已取消并退出后仍残留资源占用、阻塞后续任务的问题；依据原调用的退出证据收尾，部分效果仍待核对，不自动重跑。
- 修复本机工具被旧资源占用长期阻塞、只报 `fetch failed` 的问题；工具已返回的结果不会因收尾异常丢失，也不会被误判为尚未执行。
- 五个平台内置 kvault 统一升级到 **0.5.0-rc.2**。修复凭据排队、超时、取消与断链恢复，避免将本地读取故障误报为模型网络 502；凭据重试不重放已执行工具。
- 补齐解锁、启动票据与旧 Vault 升级的凭据身份登记；修复旧脚本凭据导入和历史未知删除核对，核对不读取秘密、不重复删除。
- 模型可恢复断线只重试失败步骤，保留已完成工具结果；审批与工具控制响应丢失时核对原调用回执，避免重复批准或执行。
- 修复微信上下文失效后反复提交、通知持续被拒收的问题；真实平台冷却仍然生效，已接受、已失败和结果未知的发送不会因续接而自动重发。
- 自动恢复会核对原任务版本、暂停状态和原有效时限；响应丢失、重启或重复扫描不会重复恢复。凭据、审批、输入及未知效果需要本人处理时，报告明确说明。
- 浏览器只读抓取使用独立页面，不覆盖正在操作的表单；仅对确定的只读导航失效有限恢复，交互提交不自动重放。
- 修复启动交接、升级放行和服务排空后的就绪状态误报；管理页面可达与业务可用分别显示。
- 修复任务记录首屏读取失败时，后台轮询清掉错误和重试按钮的问题；空列表自动检查后也不再停留在加载状态。
- 修复历史图片、工具图片和 MCP 图片的内容投影与引用；保持材料来源、版本和会话范围，避免跨会话串用。
- 修复 Agent 创建、绑定、结果交接与用量记录在冲突或中断后的恢复；普通项目和对话编辑保留已有绑定。
- 能力目录明确区分临时 Worker 的组合候选与当前助理的直接工具；关闭临时组建时，不再展示本轮不可执行的组合工具与技能，固定 Agent 仍独立处理。
- 成员回报能力缺口、频道成员分派等角色专用工具不再暴露给根助理；越界调用明确返回未执行，避免落入数据库参数错误。
- 优化项目根缓存、执行历史筛选索引和空闲成果扫描，减少重复数据库读取与后台开销。

## UX improvements

- 对话显示当前助理及配置来源，项目和对话提供「助理与协作」入口；手机端可完成配置并保留高级管理入口。
- 执行、成果和通知分别显示真实阶段与等待原因；微信接收正常、通知暂存、恢复核验和平台冷却不再混为同一状态。
- 「恢复通知」命令使用独立代码块，方便复制；通知详情支持查看前序阻塞、发送时间及补发预演。
- 巡检报告显示实际检查范围、恢复结果和仍需本人处理的项目；已解决的等待不再计入当前问题数量。
- 凭据错误使用明确说明，区分临时繁忙、通信故障和未解锁；本机与 SSH 工具结果标明执行来源，减少误诊。
- 保存冲突保留草稿；凭据目录刷新保留展开状态，迟到响应和失效确认框不会继续操作过期对象。

## Breaking changes

- `maintenance_finish` 的自动动作必须提供当前观察到的 `expectedJobVersion`。旧自动恢复记录缺少任务约束快照时转人工核对，不猜测版本或原时限。
- 新 Agent、媒体历史和活动通知恢复记录不能交给不支持它们的旧版本接管。需要回退时，先停服并按兼容条件恢复独立、完整的升级前实例。
- 升级不自动修改现有定时任务、开启恢复授权或创建长期 Agent；上层关闭的协作或模型能力不能由较小范围重新开启。

沿用原实例目录、配置、Vault 和主密码。先停服并核对进程退出，再替换程序、启动并按需解锁；仅替换文件不会更新正在运行的旧进程。

提供 macOS ARM64、Linux ARM64/x64、Windows ARM64/x64 CLI，以及 macOS 和 Windows 桌面包。macOS 桌面包提供 ZIP 和 DMG，使用 ad-hoc 签名，未经 Apple 公证；Linux/Windows 为交叉构建，不能视为目标平台原生运行验收。使用发行签名、`SHA256SUMS` 和 `release-manifest.json` 核对构件。
