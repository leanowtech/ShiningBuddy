# Shining Buddy v0.9.8-rc.6

## New features

- 新增定时巡检与受限恢复能力。本人可指定允许检查的项目、恢复动作和预算，模型核对后续接未完成的运行，或恢复已证明未发送的原有结果。
- 提供 CLI 授权和巡检报告入口，可查看哪些已恢复、仍在运行，以及哪些需要本人处理。

## UX improvements

- 微信恢复通知命令使用独立代码块，可一键复制，操作方式与登录审批保持一致。
- 巡检结果明确区分检查完成、恢复排队、恢复完成和通知状态，减少“显示成功但实际没检查”的困惑。
- 报告显示检查范围、数量和覆盖状态；不再把未检查的范围当作没有问题。

## Bug fixes

- 修复定时任务缺少巡检工具的问题；缺少有效授权、未完成翻页或没有提交巡检回执时，不再记录为巡检成功。
- 防止重复扫描、响应丢失和进程重启导致重复恢复；保留原成果、通知时间和微信发送限制。
- 内容拒绝、凭据或批准需求、执行与发送结果不确定时，明确交由本人处理，不盲目重试。

## Breaking changes

- 无。升级不会自动修改现有任务或授予恢复权限；需要本人另行配置启用。
