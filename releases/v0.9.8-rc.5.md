# Shining Buddy v0.9.8-rc.5

## New features

无新增功能，本版集中修复稳定性问题。

## UX improvements

- 凭据读取失败时显示易懂的原因说明，不再直接展示内部错误 JSON。
- 区分临时读取故障与凭据未就绪，避免把繁忙或超时误导成密码错误。

## Bug fixes

- 修复本地凭据读取失败被误报为“模型上游网络 502”。
- 修复凭据请求排队、超时和取消处理，避免过期请求继续执行或阻塞后续请求。
- 统一凭据读取重试，避免多层重复重试；不会自动重放写入或结果未知的操作。
- 修复清理失败覆盖已成功结果的问题，避免误报失败或重复请求模型。
- 修复 kvault 会话收尾时偶发丢失操作响应、被报为通信失败的问题。

## Breaking changes

无。沿用原实例数据、Vault 和主密码，按原流程替换程序并重启即可。
