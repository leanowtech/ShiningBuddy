# Shining Buddy v0.9.9-rc.3

## New features

- 定时任务可只保留最新未开始的一轮，也可设置计划开始的有效期。

## Bug fixes

- 模型持续输出时按流空闲时限和整轮时限管理。没有结束证据的断流会保留已有进度。
- 任务成果保存及微信接单后的工作台回写可自动补齐。恢复时复用原执行和投递回执。
- 旧执行进程的影响限制在相关任务和资源。大型会话的续接核对在后台进行。
- 中断的升级可复用已核验的备份文件。回退前会核对所需空间。

## UX improvements

- 运行记录显示等待阶段、最近进展及实际截止时间。
- 修复协作等待凭据时误显示已完成、候选读图能力不符，以及重新打开对话后阅读位置偏移。

## Breaking changes

- 无。沿用现有实例格式和 kvault 0.5.0-rc.2。
