# Shining Buddy v0.9.9-rc.2

## New features

- 在对话中预览当前会话有权访问的成果，并按需展开对应的工具记录。

## Bug fixes

- 模型已返回结果时，本机用量结算确认丢失不会再把这轮误报为模型超时。Host 可补记原回执，同一笔用量只入账一次。
- 模型连接中断后，按已保存的步骤与提交回执判断能否恢复，避免重复调用已执行的工具或重复提交已有结果。
- 改善本机凭据读取与 Shell 退出核对。已证实结束的本机执行可释放占用，后台任务能继续使用对应工具。
- 修复历史消息触顶不加载、加载后跳动或排序错位，以及仅有过程内容时出现空白回复的问题。

## UX improvements

- 正式回复和运行过程分开展示。回看早期消息时保留阅读位置，首次加载优先显示正文，工具详情展开时再加载。
- 精简任务等待与故障提示，区分模型连接、凭据访问和本机结算。
- 当模型的上下文窗口较小时，仍可按需查找当前范围内可用的工具和技能。

## Breaking changes

- 无。沿用现有实例格式与 kvault 0.5.0-rc.2。
